```bash
npm create ollin@latest my-game
```

*Ollin* is Nahuatl for *movement*. In the Mexica calendar, *Nahui Ollin* (4 Movement) is the sign of the Fifth Sun, the era we live in.

<CardGrid>
  <Card title="Fast" icon="rocket">
    Component data lives in typed arrays that go straight to the GPU. With 20,000 moving sprites Ollin spends about 3.5x less main-thread time per frame than Phaser.
  </Card>
  <Card title="Small API" icon="pencil">
    `createGame`, `spawn`, `query`, `system`. A scene is a function, and hot reload restarts it when you save.
  </Card>
  <Card title="Batteries included" icon="puzzle">
    Sprites, animation, text with accents, a camera, tweens, GPU particles, input, audio, Tiled maps and devtools.
  </Card>
  <Card title="Plugins" icon="setting">
    WebGL2 or WebGPU, Rapier physics through WASM, and your own plugins: each one is a plain function.
  </Card>
</CardGrid>
