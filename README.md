# Ollin site

Website and documentation of [Ollin](https://github.com/Tlapalli/ollin), built with [Astro Starlight](https://starlight.astro.build) and published to GitHub Pages: https://tlapalli.github.io/ollin-site/

```bash
npm install
npm run dev      # http://localhost:4321/ollin-site/
npm run build    # dist/
```

Pages live in `src/content/docs/`. Every push to `main` deploys.
