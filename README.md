# Tlapalli site

Website of [Tlapalli](https://github.com/Tlapalli), an independent game studio, and of its open-source engine [Ollin](https://github.com/Tlapalli/ollin), with the engine's docs. Built with [Astro](https://astro.build) and [Starlight](https://starlight.astro.build), published to GitHub Pages: https://tlapalli.github.io/

```bash
npm install
npm run dev      # http://localhost:4321/
npm run build    # dist/
```

Every push to `main` deploys.
